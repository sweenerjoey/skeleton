This is Skeleton: lightweight, mobile-first infrastructure for web-based projects. Use it as a starting point for your next digital design system or web page.

About The Project

1.0.0

Inspired by Dave Gamache's framework of the same name, this is my attempt at creating a reusable, mobile-first backbone for my web-based projects.

My version of the skeleton focuses on the CSS grid, establishing an extensive list of utility classes that are applied in HTML to dictate an element's placement on the grid, configurable at multiple breakpoints.

This, ideally, makes writing the HTML more 'designer-friendly,' for me and for others.

Additionally, this framework establishes an inheritance-based spacing scale, where modifying one base value (default 1rem) will cascade across the whole framework, hoping to eliminate as many "magic numbers" in the code as possible. Elements are always related to other elements.

Finally, no visual characteristics are applied through the skeleton, like fonts and colors: a side-car 'theme.css' file handles those declarations separately. This allows for per-project themes and styling, or for entire design systems to be built on top of the skeleton with ease.
